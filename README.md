# 森林漫步 Forest Walk

一個沉浸式的互動網站，讓人在瀏覽器裡慢慢走一段森林。沒有分數、沒有計時、沒有目的地——只有影像、聲音，和願意停下來的片刻。

（建議戴上耳機）

## 這是什麼

11 個場景串成的分支路徑，8 個在主線上、3 個是走岔了才會遇到的支線。點擊畫面中發光的位置往前走，沿途會經過 6 個「停留點」——那裡有專屬的音樂和一段短文，邀請你停一下再走。

走到哪裡會自動記住，關掉分頁明天再回來，可以接著走。

## 體驗設計

| | |
|---|---|
| **分支場景** | 11 個場景、主線與支線並存，走法不只一種 |
| **影片背景** | 6 個場景使用循環影片，交叉淡入淡出、無接縫感 |
| **分層音景** | 背景音樂之外，各場景疊加溪流、鳥鳴、瀑布、林風等環境音 |
| **停留點** | 6 個停留點，各有專屬配樂與文字 |
| **進度保存** | 自動記錄探索進度，可隨時離開後繼續 |
| **響應式** | 手機與桌面皆完整支援 |

## 技術實作重點

這個專案的難處不在功能多，而在「不能讓使用者察覺到技術」——任何一次閃爍、破音或載入延遲，沉浸感就斷了。實作上主要處理三件事：

**影片無縫循環**
場景背景是短影片，直接 `loop` 會在接點產生可見的跳動。改以雙層 `<video>` 交叉淡入淡出：在當前片段剩餘 3.5 秒時啟動另一層並開始轉場，兩層疊加完成交接，消除接縫。

**音量以 dB 校準而非憑感覺**
環境音要能疊加而不互相蓋過，音量必須有一致基準。各音軌以分貝值換算為線性音量後才設定（例如溪流 `-10dB ≈ 0.316`、環境底噪 `-23dB ≈ 0.071`），讓多層聲音同時存在時仍保持層次。以 Howler.js 管理，全域單例避免場景切換時重複建立實例。

**預載入與轉場穩定性**
進入場景前預先載入下一個可能的目的地，以 Set／Map 去重並快取 Promise，避免同一張圖重複請求；載入失敗也一律 resolve，不讓單張圖卡住整段流程。場景轉場另行處理亮度連續性，避免切換瞬間的白閃。

## 技術棧

Vue 3（Composition API）· Vite · Pinia · Tailwind CSS · Howler.js
部署：GitHub Actions 自動建置並發布至 GitHub Pages

## 本機開發

```bash
cd forest-walk
npm install
npm run dev
```

其他指令與詳細的專案結構、場景資料格式說明，見 [forest-walk/README.md](forest-walk/README.md)。

## 專案結構

```
.
├── forest-walk/          # 應用程式主體（Vue 3 + Vite）
│   ├── src/
│   │   ├── components/   # 場景、熱區、指引面板、播放器等
│   │   ├── composables/  # 音訊控制、資源預載
│   │   ├── stores/       # Pinia 狀態與進度保存
│   │   └── data/         # 場景與停留點資料（JSON 驅動）
│   └── public/           # 影像、影片、音訊素材
├── docs/                 # 設計規格文件
└── .github/workflows/    # GitHub Pages 自動部署
```

場景與停留點皆由 `src/data/` 下的 JSON 定義，新增一個場景不需要改動元件程式碼。
